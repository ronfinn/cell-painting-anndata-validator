| Security vulnerability | Private advisory — see [`SECURITY.md`](SECURITY.md) |

## Before opening an issue

1. Check the docs (especially troubleshooting and the rule catalogue).
2. Confirm the package version (`cp-validate --version`).
3. Prefer a **minimal synthetic** reproduction.
4. Do **not** upload private or sensitive datasets.

## Maintainer expectations

This is a small open-source project. Responses are best-effort. There is no
SLA and no commitment to review proprietary data offline.
