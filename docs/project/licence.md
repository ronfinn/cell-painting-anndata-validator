## Citation

Use `CITATION.cff` at the repository root. Example:

```bibtex
@software{cp_anndata_validator,
  title = {Cell Painting AnnData Validator},
  author = {Finn, Ron},
  version = {0.2.0b1},
  url = {https://github.com/ronfinn/cell-painting-anndata-validator}
}
```

Update the version string to match the release you used.
