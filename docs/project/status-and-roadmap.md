# Status and roadmap

## Status (0.2.0b1)

Public **beta**. The CLI, `validate()` API, built-in schemas (`0.2.1`),
stable rule codes, and console/JSON/HTML reports are in place. Real LINCS
and JUMP Cell Painting Gallery well-level pilots have been exercised outside
the repository (see [Public-data pilots](../pilots/index.md)).

## Near-term roadmap

- Continue schema alias calibration from public evidence (issue forms welcome)
- Documentation and packaging polish for a final `0.2.0`
- Optional deeper `.uns` block schemas where public conventions exist
- Clearer guidance for embedding-style feature names (`FEAT001`)

## Explicit non-goals (current)

- Format conversion into AnnData
- Automatic repair of datasets
- Biological suitability scoring
- Zarr input
- Automated PyPI publication without a human decision
